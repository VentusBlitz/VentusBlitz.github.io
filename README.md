# ✦ CharacterGuesser

**How well do you really know your favourite fictional worlds?**

CharacterGuesser is a fan-made character trivia game inspired by Wordle.
Identify a mystery character using clues about their species, gender,
house, blood status, affiliations, and first appearance.

**[Play CharacterGuesser](https://ventusblitz.github.io/)**

------------------------------------------------------------------------

## 🎮 About the Game

Each round gives you one randomly selected mystery character. Your
objective is to identify them within **20 guesses**.

After every guess, the game provides colour-coded feedback to help you
narrow down the answer.

### Colour Guide

  Colour      Meaning
  ----------- --------------------------------------
  🟩 Green    Correct match
  🟨 Yellow   Partial match or related information
  🟥 Red      Incorrect match

### Character Attributes

Every guess is evaluated across seven categories:

-   **Character** -- The character's name.
-   **Species** -- Their species or nature.
-   **Gender** -- Their gender.
-   **House** -- Their Hogwarts house, where applicable.
-   **Blood Status** -- Their wizarding blood status.
-   **Affiliations** -- Groups, organisations, families, or other
    associations.
-   **First Appearance** -- The book or film in which they first
    appeared.

Affiliations support partial matching, allowing you to identify shared
groups and organisations between characters.

## ✨ Features

-   **20 guesses per round** -- A challenging but forgiving limit.
-   **Random character selection** -- A new mystery character every
    round.
-   **Live autocomplete** -- Quickly find characters as you type.
-   **Colour-coded feedback** -- Green, yellow, and red clues.
-   **Partial affiliation matching** -- Shared affiliations are
    highlighted.
-   **Detailed character attributes** -- Compare multiple aspects of
    each character.
-   **Responsive interface** -- Play on desktop, tablet, or mobile.
-   **Cyberpunk-inspired design** -- Dark purple backgrounds, neon
    accents, and themed scrollbars.
-   **Instant replay** -- Start another round as soon as you finish.

## 🛠️ Built With

CharacterGuesser is a lightweight, browser-based project built using:

-   **HTML5** -- Page structure and content.
-   **CSS3** -- Layout, animations, responsive design, and visual
    styling.
-   **Vanilla JavaScript** -- Game logic, character database,
    autocomplete, and feedback system.
-   **Google Fonts** -- Orbitron and Rajdhani typography.

There are no frameworks, backend servers, databases, or build tools
required to run the current version.

## 🚀 Run Locally

You can run CharacterGuesser directly in your browser.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/VentusBlitz/ventusblitz.github.io.git
    ```

2.  Open the project folder.

3.  Open `index.html` in your browser.

That's it! No installation or additional dependencies are required.

------------------------------------------------------------------------

## 🌐 GitHub Pages Deployment

CharacterGuesser can be hosted for free using GitHub Pages.

1.  Create a repository named `VentusBlitz.github.io`.
2.  Upload the project files.
3.  Make sure the main HTML file is named `index.html`.
4.  Open the repository's **Settings → Pages**.
5.  Select **Deploy from a branch**.
6.  Choose the `main` branch and `/ (root)` folder.
7.  Save your settings.

Your website will be available at:

**https://ventusblitz.github.io/**
